# Vsock Reconnect

Every previous connected stream was treated as invalid after reboot. The harness revalidated parent directory, owner, mode, no-symlink state, socket inode, VMM PID, process-start identity, executable digest, unit, cgroup, API socket, disk, CID, and nested-off configuration before opening a fresh mux connection. Runtime inodes changed after each reboot. Stored stale inventories were refused, then a new connection requested guest port 2222 and required a real SSH banner and strict authenticated SSH.
